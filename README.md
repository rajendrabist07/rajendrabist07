## About

I care more about *why* a system is architected a certain way than about which framework renders the button. My foundation is in semantic HTML, CSS architecture, and JavaScript's execution model — React and Next.js are tools I reach for with that understanding underneath, not shortcuts around it.

Most of my recent work sits at the intersection of **backend engineering and applied AI** — designing data models, authentication flows, and API contracts first, then building AI features (RAG-adjacent structured generation, multimodal input, streaming) on top of that foundation rather than bolting AI onto an afterthought backend.

- 🧠 Currently building **EduMethod AI** — a learning-methodology platform combining spaced repetition, multimodal topic extraction, and an adaptive AI tutor
- 🏗️ Focus areas: system design, database schema design, authentication/authorization patterns, LLM integration
- 🇳🇵 Based in Nepal — open to remote roles worldwide, and onsite/hybrid
- 🟢 **Open to full-stack & backend-focused roles**, freelance work, and technical collaborations

### 🎓 [EduMethod AI](https://github.com/rajendrabist07/edumethod-ai)
**Flagship project** — an AI-powered learning methodology platform.

Converts a syllabus (photo or raw text) into a structured 7-day study plan using learning-science principles — spaced repetition, interleaving, active recall — plus an adaptive quiz engine with weakness detection and a multimodal AI doubt-solving coach.

Built with production patterns: Clerk-based auth, Postgres row-level security, Zod-validated AI I/O, and usage-tiered rate limiting.

`Next.js 15` `TypeScript` `Supabase (Postgres)` `Clerk` `Groq API` `Gemini API` `Tailwind CSS`
